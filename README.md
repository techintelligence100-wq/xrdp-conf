# xrdp-conf
# Kali Linux XRDP Setup  Automated Bash script to install and configure XRDP with Xfce on Kali Linux.  ## Usage 1. Make executable:    chmod +x setup_xrdp.sh 2. Run script:    sudo ./setup_xrdp.sh  # Connect Use Windows Remote Desktop Connection or Remmina on Mac/Linux with your Kali IP and credentials. Ensure you log out locally before connecting.
